# NATIONAL FPV DRONE RACING CHAMPIONSHIP 2026

Official static website package for the National FPV Drone Racing Championship 2026.

V17 adds a continuously scrolling co-organiser logo marquee using the supplied AASSC, Aeronautical Society of India, AeroVidya and SIATI logos.

Deploy the contents of this folder to the root of the GitHub Pages `main` branch.


### Sponsor placeholders (V20)
Six temporary sponsor logo placeholders are included. Replace the corresponding `sponsor-placeholder-01.svg` through `sponsor-placeholder-06.svg` files with sponsor logos as partnerships are confirmed.
